# Portfólio Pessoal

Site de portfólio pessoal desenvolvido para a disciplina Fundamentos da Programação Web.

## Tecnologias

- HTML5
- CSS3 puro
- JavaScript puro

## Funcionalidades

- Site em página única com navegação por âncoras
- Alternância entre português do Brasil e inglês
- Alternância entre tema claro e tema escuro
- Menu responsivo para telas menores
- Formulário de contato com validação em JavaScript

## Estrutura

```txt
index.html
css/
  style.css
js/
  script.js
```
